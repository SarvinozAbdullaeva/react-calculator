# React Calculator

A simple calculator built with React.js (Vite). Supports addition, subtraction,
multiplication, division, and reset.

# You can view and interact with the live application here:
https://sarvinozabdullaeva.github.io/react-calculator/

## Tech stack
- React 18
- Vite

## Run locally
```
npm install
npm run dev
```
Then open the local URL Vite prints (usually http://localhost:5173).
